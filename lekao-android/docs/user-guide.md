# Lekao Android · 用户使用指南

> V1.0.0 · 面向培训机构助教 / 中小学老师 · 安装即用

---

## §1 · 这是什么 APP？

Lekao 是一款**手机端 AI 助教助手**，帮老师在教室里**拍照 → AI 一键生成课堂小结 / 作业反馈 / 错题集**。

**核心场景**：
- 📸 拍一张板书 / 讲义 / 作业 → AI 自动识别 + 总结
- ✍️ 输入一段学生表现 → AI 生成正向反馈
- 📚 拍错题 → 自动归档 + 导出 docx → 一键发家长群

**对接 Web**：[lekao.asterforge.top](https://lekao.asterforge.top) — 账号、灵感墙、T-Coin 余额**完全同步**。

## §2 · 安装

### 2.1 系统要求

- Android 8.0+（API 26+）
- 任何品牌（华为 / 小米 / OPPO / vivo / 三星 / Pixel / ...）

### 2.2 安装步骤

1. **下载 APK**（机构群发的链接 / 邮件附件）
2. 点 APK 文件 → 系统提示"允许安装未知来源应用" → 去设置开权限
3. 返回点"安装" → 等 5 秒 → 完成
4. 桌面找 "Lekao" 图标 → 点开

> ⚠️ **为什么不是应用商店？** 用户原话"不用上架"。群发安装是当前阶段最快的方式。

### 2.3 首次启动

启动后看到 **Lekao 蓝色启动屏**（带 Lottie 动画）+ **自动尝试登录**：

| 情况 | 结果 |
|------|------|
| 已登录（Web 端登录过 / 之前用 Lekao App）| 直接进 Dashboard |
| 未登录 | 跳到登录页 |

## §3 · 登录

### 3.1 邮箱密码登录

```
1. 登录页 → 切到"密码登录"
2. 输入邮箱 + 密码
3. 点"登录"
4. 进 Dashboard
```

> 💡 密码忘记？点"忘记密码" → 输入邮箱 → 收验证码 → 设新密码。

### 3.2 邮箱验证码登录（推荐 · 免记忆密码）

```
1. 登录页 → 默认"验证码登录"
2. 输入邮箱 → 点"发送验证码"
3. 收邮件（可能进垃圾箱）→ 复制 6 位数字
4. 粘贴到"验证码"输入框（自动识别剪贴板）
5. 点"登录"
```

### 3.3 生物识别登录（M04 · 二次确认）

登录后，下次开 App 自动提示"使用指纹 / Face ID 解锁"。

**开启方式**：登录成功 → 跳 Dashboard → 提示"启用生物识别" → 选"启用"。

**支持的设备**：
- 指纹识别（绝大多数 2018+ 设备）
- Face ID（部分设备，如 Pixel 4+ / 华为 Mate 20 Pro+）
- **不支持**纯密码 PIN（需要生物硬件）

## §5 · 课堂小结

### 5.1 用法

```
1. Dashboard → 点"课堂小结"
2. 选择图片来源（3 选 1）：
   - 📷 拍照（系统相机）
   - 🖼️ 相册（最多 9 张）
   - 📋 粘贴（截图后 Ctrl+V 即可）
3. 选模板（系统 / 自定义，V1.0.0 只用默认）
4. 点"AI 生成小结"
5. 等 5-15 秒 → 文字流式显示
6. 复制 / 分享 / 重新生成
```

### 5.2 输出格式

```
📋 课堂小结

【学科】数学
【主题】一元二次方程
【重点】配方法、判别式
【学生表现】3 个学生掌握较好，2 个学生需要课后辅导
【作业建议】完成课本 P23-25
```

### 5.3 计费

每次生成消耗 **1 T-Coin**（流式输出本身就慢，不限速）。余额 < 1 时按钮置灰。

### 5.4 OCR 增强（M16 · V1.0.0）

- 拍照后**自动**OCR 识别手写板书
- 支持中文 / 英文 / 日文 / 韩文 / 印地文 / 拉丁
- 公式模式（FORMULA）会预处理为灰度 + 对比度增强，保留数学符号

## §6 · 课堂反馈

### 6.1 用法

```
1. Dashboard → 点"课堂反馈"
2. 文字输入框：写学生表现（例 "小明今天举手 5 次，回答正确 3 次"）
3. 选"正向" / "中性" / "建设性" 风格
4. 点"AI 生成反馈"
5. 流式显示反馈 → 复制
```

### 6.2 输出示例

正向：
```
小明今天表现非常棒！积极举手发言，回答问题准确率高，思维敏捷。建议继续保持这种学习热情。
```

建设性：
```
小明的课堂参与度有进步空间，建议老师多提问、多鼓励，培养他的表达自信。
```

### 6.3 计费

每次消耗 **0.5 T-Coin**（比小结便宜，因为输入短）。

## §7 · 错题集

### 7.1 拍照

```
1. Dashboard → 点"错题集"
2. 点"拍照"按钮 → 系统相机
3. 拍 1-9 张错题
4. 选科目（数学 / 语文 / 英语 / 物理 / 化学 / 生物 / 道法 / 历史 / 地理）
5. （可选）进入标注页：涂鸦 / 箭头 / 裁切 / 文字
6. 点"上传"
```

### 7.2 标注（M06）

拍照后进入标注页：
- ✏️ **涂鸦**：自由画笔（红/蓝/黑/白 4 色）
- ➡️ **箭头**：直线箭头
- ✂️ **裁切**：拖框选错题区域
- 🔤 **文字**：添加文字注释
- ↩️ **撤销**：撤销上一步

### 7.3 OCR（M16）

标注完成后点"识别" → 自动 OCR → 文字显示在下方 → 可手动修改。

### 7.4 智能裁切（M10）

上传前自动识别错题边界，弹出"是否裁剪" → 确认后自动裁 → 节省存储。

### 7.5 草稿箱（M09 · 离线）

**断网时**：所有错题自动存到本地 Room 数据库（草稿箱）。
**网络恢复**：自动同步到服务端（WorkManager 后台跑）。
**手动同步**：草稿箱页 → 右上角"立即同步"。

### 7.6 导出 docx（M05）

```
1. 错题列表 → 勾选要导出的错题
2. 点"导出 docx" 按钮
3. 等 5-10 秒生成 → 弹出分享菜单
```

### 7.7 一键发家长群（M03 · 用户原话"一键发家长群"）

导出后选择分享：
- 💬 **微信** → 选好友 / 群 → 发送
- 💼 **钉钉** → 同上
- 📧 **邮件** → 选收件人
- 📋 **复制到剪贴板** → 手动粘

> 💡 docx 包含所有错题图片 + 文字 + 标注，**不**含学生姓名（隐私）。

## §8 · 灵感墙

### 8.1 浏览

```
1. Dashboard → 点"灵感墙"
2. 列表显示所有公开灵感（按"最新" / "最热" / "评论数" 排序）
3. 顶部 TOP 3 卡片（点赞数前 3）
4. 点任意灵感 → 看详情 + 评论
```

### 8.2 提交

```
1. 灵感墙 → 右上角"+"按钮
2. 输入标题 + 内容
3. 添加标签（可选 · 最多 5 个）
4. 点"发布"
```

### 8.3 评论 + 点赞

- **点赞**：点心形图标（再点取消）
- **评论**：详情页底部"写评论" → 输入 → 发送

### 8.4 实时刷新（M17 · SSE）

灵感墙打开时**自动**连接 SSE：
- 别人点赞 → 你这边数字 +1（无需刷新）
- 别人评论 → 实时显示

> 💡 灵感墙切到后台 → SSE 自动断开 → 切回前台 → 自动重连。

## §9 · 个人中心

### 9.1 改资料

```
Settings → 昵称 → 输入新昵称 → 保存
```

### 9.2 主题色（M13 · V1.0.0）

5 套主色可选：
- 🔵 蓝（默认 · 复用 Web）
- 🟠 珊瑚
- 🟢 翡翠
- 🟣 紫
- 🟡 琥珀

**选择后立即生效**（不需要重启 App）。

### 9.3 深色 / 浅色 / 跟随系统

- **浅色**：永远浅色
- **深色**：永远深色（夜间护眼）
- **跟随系统**：跟系统设置走（推荐）

### 9.4 多语言（M14 · V1.0.0）

- 🇨🇳 简体中文（默认）
- 🇺🇸 English

**切换方式**：
- 在 App 内：Settings → 语言 → 选 → 立即生效
- 在系统设置：系统设置 → 语言 → 选 → App 收到 `onConfigurationChanged` → 自动切

### 9.5 退出登录

Settings → 底部"退出登录" → 二次确认 → 回到登录页。

**安全清理**（参考 [`CookieManager.kt`](../app/src/main/java/com/lekao/app/data/api/CookieManager.kt)）：
- OkHttp cookie 立即清
- DataStore 清空
- 下次打开需重新登录

## §10 · 推送通知（M12 · V1.0.0）

### 10.1 三种通知

| 类型 | 触发 | 颜色 | 优先级 |
|------|------|------|--------|
| 💡 **灵感墙** | 关注的灵感有新评论 / 点赞 | 蓝 | 默认 |
| 🛡️ **系统** | 平台公告 / 维护通知 | 灰 | 低 |
| 💬 **评论被回复** | 你评论的灵感被回复 | 绿 | 高 |

### 10.2 同灵感评论合并

同一灵感的 3 条新评论 → 合并显示为 1 个"灵感 X 收到 3 条新评论"（点开看全部）。

### 10.3 关闭通知

- 单类通知：系统设置 → 通知 → Lekao → 关对应 channel
- 全部关：系统设置 → 通知 → Lekao → 关

## §14 · 常见问题 FAQ

### Q1：登录后立刻掉线？

**A**：服务端 session 过期（默认 30 天）。重新登录即可。

### Q2：课堂小结生成失败？

**A**：
1. 检查余额（Dashboard 顶部）
2. 检查网络（流式输出需要稳定连接）
3. 缩小图片（> 4MB 可能被服务端拒）
4. 重试

### Q3：错题集 OCR 识别乱码？

**A**：
1. 拍照时**正对**错题，避免倾斜
2. 光线充足，避免阴影
3. 切换到 FORMULA 模式（数学题专用）
4. 手动修改文字（OCR 后可编辑）

### Q4：推送通知收不到？

**A**：
1. 系统设置 → 通知 → Lekao → 全部打开
2. 系统设置 → 电池 → Lekao → "不优化"
3. 国内手机（华为 / 小米）额外关"自启动管理"

### Q5：App 占用存储大？

**A**：
- 错题图片占大头（标注后的高清图）
- 定期清理：Settings → 存储 → 清理本地缓存
- 或卸载重装（云端数据不丢）

### Q6：跟 Web 端数据同步吗？

**A**：**完全同步**。
- 登录态 / T-Coin 余额 / 灵感墙 / 错题集（云端部分）— 都同步
- 标注 / 草稿箱（本地部分）— 只在 App 内

### Q7：iOS 端有吗？

**A**：**暂无**。V2.0.0 计划，需要买 Mac（目前用 Windows 开发）。

### Q8：能装 Google Play / 应用宝吗？

**A**：**不计划**。用户原话"不用上架"。当前通过群发 APK 安装。

### Q9：App 闪退？

**A**：
1. 关闭后台 → 重开
2. 卸载重装（数据云端不丢）
3. 反馈：Settings → 关于 → 反馈问题（附 logcat）

### Q10：登录页"忘记密码"点了没反应？

**A**：检查网络 + 邮箱是否在垃圾箱。**T-Coin 余额 / 用户信息** 完全不影响重置。
